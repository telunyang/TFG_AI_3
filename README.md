# 人工智慧技術應用實作班

從**機器學習**的資料處理與模型訓練出發，逐步探索**文字分類、電腦視覺、大型語言模型、生成式 AI 與 AI Agent**，透過生活情境、互動圖解與實作流程，理解 AI 如何從資料中學習、產生結果，進一步協助完成任務。

本專案整理了面向**高中生**的教學教材，以**繁體中文（臺灣）**製作，共有 **7 個教學主題、14 節課**。每個主題均提供互動式 HTML 投影片，並安排概念操作與課堂檢核，協助建立從原理到應用、從結果到驗證的完整觀念。

## 課程目標

- **理解 AI 的基本流程：**認識資料、特徵、模型訓練、推論與評估之間的關係。
- **掌握不同 AI 任務：**區分預測、分類、分群、影像辨識及生成式應用。
- **理解現代 AI 技術：**認識 BERT、LLM、影像生成與 AI Agent 的核心概念及使用情境。
- **培養實作與驗證能力：**透過互動操作、案例分析與課堂檢核，學習判讀結果、發現限制並注意安全與責任。

## 課程大綱與教學主題

### 01｜機器學習與模型訓練

**從一份資料表開始，理解模型如何學習並進行預測。**先認識樣本、特徵與標籤，以及缺漏值處理、標準化、One-Hot Encoding、訓練集與測試集；再透過迴歸、邏輯斯迴歸、正則化、PCA 與 K-means，了解模型訓練、效能評估和過度擬合等概念。

**教材：**[01_機器學習與模型訓練.html](01_機器學習與模型訓練.html)

### 02｜資料預測與模型實作

**不只要做出預測，還要知道模型何時會判斷錯誤。**從校園信箱分類案例理解混淆矩陣、Accuracy、Precision、Recall 與 F1-score，並比較 SVM、Kernel 與決策樹；接著學習資料切分、交叉驗證、Grid Search，以及 Bagging、Boosting 和隨機森林，練習公平比較與選擇模型。

**教材：**[02_資料預測與模型實作.html](02_資料預測與模型實作.html)

### 03｜AI 分類模型應用

**讓電腦理解文字，並將文字分到適當的類別。**以班群留言及園遊會資料為例，認識 Tokenizer、Embedding、Self-Attention、Transformer Encoder 與 BERT；進一步了解文字標註、模型微調、Batch、Epoch、Learning Rate、Loss，以及如何避免資料洩漏並評估文字分類成果。

**教材：**[03_AI分類模型應用.html](03_AI分類模型應用.html)

### 04｜電腦視覺與影像辨識

**從像素與色彩出發，探索 AI 如何看懂照片與影片。**先操作 RGB、灰階、解析度、亮度、對比、模糊與邊緣偵測等影像處理概念；再以 YOLO 介紹物件偵測、Bounding Box、正規化座標、IoU、NMS、資料標註、模型微調及影片追蹤。

**教材：**[04_電腦視覺與影像辨識.html](04_電腦視覺與影像辨識.html)

### 05｜大型語言模型應用

**理解聊天型 AI 如何產生文字，以及如何提出更清楚的需求。**介紹 Token、Context Window、提示詞設計、訊息角色、輸出格式與 Temperature 等生成參數；接著探討雲端與本機模型、API、多輪對話、對話記憶、聊天介面設計、Vibe Coding，以及提示詞注入與回答驗證。

**教材：**[05_大型語言模型應用.html](05_大型語言模型應用.html)

### 06｜生成式 AI 實務應用

**從文字描述出發，規劃圖片、音樂與影片作品。**先以校園海報認識文字生圖、雜訊逐步生成、Prompt、構圖、Seed、推論步數與 CFG；再透過活動配樂及短片規劃，理解節奏、音色、鏡頭運動、影格連續性與分鏡，並學習檢查作品品質及公開使用的注意事項。

**教材：**[06_生成式AI實務應用.html](06_生成式AI實務應用.html)

### 07｜AI Agent

**從「回答問題」走向「使用工具完成任務」。**以校慶活動公告為貫穿案例，了解 Agent 的任務規劃、工具呼叫、執行回饋、工作紀錄及 Skill；接著練習查核資料來源、辨識提示詞注入、掌握工具權限與人工確認，並認識 Windows 桌面端與 Colab／Ollama 遠端模型的連線情境。

**教材：**[07_AI_Agent.html](07_AI_Agent.html)

## 教材特色

- **生活化情境：**以校園信箱、班群留言、園遊會、活動海報及校慶公告等案例連結 AI 概念。
- **互動式視覺化：**利用滑桿、按鈕、圖表與流程示意，觀察參數及條件改變造成的差異。
- **循序漸進：**各主題分成兩節，由基本概念延伸至應用、實作流程與結果判讀。
- **即時檢核：**各節結束時提供互動選擇題，協助確認核心觀念。
- **重視可靠性：**將資料品質、泛化、評估方式、內容查核、使用權限與 AI 安全納入教學。

## 如何使用教材

1. 點選上方各主題的 **HTML 教材連結**，或從儲存庫下載對應的 `.html` 檔案。
2. 使用現代網頁瀏覽器開啟下載的 HTML 檔案，即可閱讀互動投影片。
3. 依投影片上的導覽按鈕切換頁面，操作圖表、滑桿或選項，並完成各節課的檢核。

> **說明：**投影片中的部分互動內容為教學模擬，用於說明 AI 原理與流程，不代表已連接或實際執行對應模型。涉及外部模型、API、Colab 或 Ollama 的延伸實作，需另行準備相關環境。

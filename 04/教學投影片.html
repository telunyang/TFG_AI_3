01 / 先認識 HTML

網頁的基本零件：Tag · Element · Attribute

一小段 HTML
<body>
  <h1 id="title">校園公告</h1>
  <ul id="news-list">
    <li class="card">
      <a href="#post-1">看更多</a>
    </li>
  </ul>
</body>
HTML 用標籤描述內容結構；元素可以包含其他元素。

Tag 標籤

<a>、</a> 是開始／結束標籤。

Element 元素

<a>看更多</a> 是一個完整元素。

Attribute 屬性

id、class、href 會提供額外資訊。

02 / 理解階層，才會寫選擇器

HTML 是一棵樹：父 → 子 → 孫

<ul id="news-list"> 父元素
<li class="card"> 子元素
<a href="...">看更多</a> 孫元素
<li class="card">…</li> 兄弟元素
</ul>

往內一層＝子層

li 是 ul 的直接子元素。

往內兩層＝孫層

a 是 ul 的後代，但不是直接子元素。

同一層＝兄弟

兩個 li 都在同一個 ul 裡面。

看 HTML 時先問：誰包住誰？誰和誰同層？
03 / CSS Selector 基本四種

同一份 HTML，可以用不同條件找元素

元素a選所有 a 連結
ID#ul-01id 等於 ul-01
Class.ccclass 清單含 cc
屬性[href]具有 href 屬性
加上條件，選得更準確
a[href]
# a 元素，而且有 href

a[href="#more"]
# href 必須剛好等於 #more

a[href^="#"]
# href 必須以 # 開頭
.cc 和 #cc 不同；
[href] 和 [href="#more"] 也不同。
04 / CSS Selector 進階：同時滿足所有條件

多個 Class、多個 Attribute 可以連著寫

同一個 a 元素，具有這些屬性
<a
  class="link primary pinned"
  href="#more"
  data-role="detail"
>看更多</a>

三個 Class：link、primary、pinned

兩個 Attribute：href、data-role

條件中間不能加空白，否則會變成查找後代元素。
a.link.primary.pinned

同一個 a，同時具有 3 個 class。

a[href="#more"][data-role="detail"]

同一個 a，2 個屬性都符合指定值。

a.link.primary[href="#more"]

可以把元素、Class、屬性混合使用。

li.cc[data-type="notice"]

同時符合 class 與另一個屬性值。

通式：元素.類別1.類別2.類別3[屬性1="值1"][屬性2="值2"]（條件全部要符合，且屬於同一個元素）
05 / 最重要的符號：空白 與 >

空白 找後代，> 只找直接子元素

<ul id="ul-01">
  <li class="cc">
    <a href="#more">看更多</a>
  </li>
  <li class="cc">
    <div class="item-body">
      <a href="#about">關於</a>
    </div>
  </li>
</ul>

第一個 a 在 li 下一層；第二個 a 還要經過一個 div。

CSS Selector結果
ul#ul-01 > a0 個
ul 下沒有直接的 a
ul#ul-01 a2 個
任何深度的後代 a
ul#ul-01 > li2 個
兩個直接子 li
ul#ul-01 > li > a1 個
只找到第一個 a
A B＝在 A 內找任何層級的 B；A > B＝只在 A 的下一層找 B。
06 / 立刻驗證：互動式 CSS Selector 練習場

改一個 Selector，被選中的元素就不同

<div id="board">

  <li class="cc hot featured" data-type="notice">

 </ul>

  • 關於
校園幫助

08 / Python：先取得伺服器的回應

requests.get()：向網址發送 GET 請求

# Import the HTTP library.
# 匯入 HTTP 請求套件。
import requests

# Request the local teaching page.
# 向本機練習網頁發送 GET 請求。
response = requests.get(
  "http://127.0.0.1:8000/practice.html",
  timeout=10
)

# Decode Chinese text correctly.
# 正確解碼中文 HTML。
response.encoding = "utf-8"

# Print the status and HTML.
# 印出狀態碼與 HTML。
print(response.status_code)
print(response.text[:200])

response.status_code

HTTP 狀態碼；例如 200 是成功。

response.text

伺服器回傳的文字內容，此例為 HTML。

timeout=10

避免網路連線持續卡住；最長等待限制，不是固定睡 10 秒。

正確寫法是 requests.get(url)，不是 requests(url)。
先在 ZIP 解壓縮後的教材資料夾執行 python -m http.server 8000，才能連線到本機練習網頁。
09 / 同一套 CSS Selector 用在 BeautifulSoup

soup.select() 選多個；select_one() 選第一個

# Import the HTML parser.
# 匯入 HTML 解析器。
from bs4 import BeautifulSoup

# Parse the received HTML.
# 解析已下載的 HTML。
soup = BeautifulSoup(response.text, "html.parser")

# Select all matching links.
# 找出所有符合條件的連結。
links = soup.select("#news-list > li.card > a")

# Visit each matching element.
# 逐一處理選到的元素。
for link in links:
  # Print text and href.
  # 印出文字與連結。
  print(link.get_text(strip=True), link.get("href"))

soup.select("...")

取得所有符合 Selector 的元素，回傳列表；此例 2 筆。

soup.select_one("...")

取得第一個符合元素；找不到則回傳 None。

.get_text()、.get("href")

分別取出元素的文字、指定的 HTML 屬性。

白板上的 CSS Selector，直接放入 select()；不用改成其他定位語法。
10 / Python：讓 Chrome 自己打開網頁

Selenium：看得到瀏覽器，也能操作現在的 DOM

# Import the browser controller.
# 匯入瀏覽器控制工具。
from selenium import webdriver

# Import the CSS locator.
# 匯入 CSS Selector 定位方式。
from selenium.webdriver.common.by import By

# Maximize and open Chrome.
# 放大視窗並開啟 Chrome。
options = webdriver.ChromeOptions()
options.add_argument("--start-maximized")
driver = webdriver.Chrome(options=options)
driver.get("http://127.0.0.1:8000/practice.html")

一個元素

first = driver.find_element(
  By.CSS_SELECTOR, "#news-list a"
)
print(first.text)

多個元素

links = driver.find_elements(
  By.CSS_SELECTOR, "#news-list a"
)
for link in links:
  print(link.text)
同樣的 CSS Selector，BeautifulSoup 看 HTML 回應；Selenium 看瀏覽器 DOM。
11 / 動態元素：等它出現再找

不要猜載入時間；用 WebDriverWait 等條件

# Import explicit waiting tools.
# 匯入顯性等待工具。
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

# Wait for a fetched element in the DOM.
# 等待 fetch 新增的元素進入 DOM。
WebDriverWait(driver, 10).until(
  EC.presence_of_element_located(
    (By.CSS_SELECTOR, "li.card.dynamic")
  )
)

# Select every link after loading.
# 載入完成後取得所有公告連結。
links = driver.find_elements(By.CSS_SELECTOR, "#news-list li.card a")

# Verify four records, then close.
# 確認有四筆，再關閉瀏覽器。
print(len(links))  # 4
driver.quit()

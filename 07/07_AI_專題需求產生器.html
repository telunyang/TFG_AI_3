工作角色

點左側卡片，就能在右側修改內容。

總控：安排工作專業助手：完成任務工具：處理資料審查：檢查成果

可以依需要新增角色；每張卡片都能修改或還原。

想了解工作角色的差別？
總控安排與分派任務；專業助手負責處理指定工作；工具負責讀檔、檢索、計算等操作；審查負責檢查結果。交給 AI 開發時，會再對應到適合的 AG2 功能。
API Key 要填在哪裡？
這裡只填環境變數名稱（例如 GEMINI_API_KEY_01），不要貼真正的金鑰。AI 建立專案時會產生空白的 .env.example；你再自行建立 .env、填入金鑰。已存在的 .env 不會被覆蓋。

工作流程圖

拉動卡片標題可調整位置；拉動圓點可建立連線。

1 找到要連接的卡片2 從右側圓點拖到目標3 點箭頭可修改設定
更改網站的任務入口（選填）
Web → 工作總控 → 其他角色 → 審查 → 回到網站。
連線小技巧：也可以先點一個右側圓點，再點目標的左側圓點。
想知道箭頭代表什麼？
呼叫關係：總控可以呼叫專業助手或檢索工具；檢索工具也能在內部使用讀檔工具，不必讓總控直接呼叫所有工具。
資料依賴：只代表某階段需要另一階段的結果，不代表會自動呼叫下一個節點。
成果回傳：工具先把結果還給呼叫者；審查後的成果回到總控，再由網站顯示。

開發指令下載後，還需要準備什麼？
AI 會依你的專題建立 requirements.txt、啟動腳本與空白的 .env.example。需要 API Key 時，再由你自行建立 .env 並填入金鑰；已有的 .env 不會被覆蓋。此頁僅整理設計，不會自行執行程式。

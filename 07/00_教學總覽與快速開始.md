# 07｜AI Agent 實作教材：遠端 Ollama、Hermes Desktop、Skills 與有聲動畫

> 核對日期：2026-10-16。此教材配合《07_AI_Agent.html》，投影片作為概念引導；這份文件提供可實際操作的工作流程。命令與功能會隨版本更新；第一次授課前務必實機操作一次。

## 目標與基本架構

已知前提：**Colab T4 上已啟動 Ollama，並已取得可以連到 Ollama HTTP API 的 ngrok HTTPS URL**。本教材不再教如何建立 ngrok 隧道。

```text
Colab T4 GPU → Ollama server → ngrok HTTPS 入口
                                   │
                     ┌─────────────┴─────────────┐
                     │                           │
              本機 Ollama CLI              Hermes Desktop
              (選用，遠端連線)              (模型推論遠端)
                                                  │
                                          本機工具 / 檔案 / 瀏覽器
                                                  │
                                      Computer Use / Skills / FFmpeg
```

**重要：Ollama API 不是 Hermes Gateway。** Hermes Desktop 的 Settings → Providers → Custom Endpoints 應填 `https://你的-ngrok-網址/v1`，而不是將 Ollama 網址填入 **Settings → Gateway → Remote gateway**；後者是連線到另一台機器的 Hermes 後端，不是模型服務。

## 20 分鐘實作建議

**第一節（約 20 分鐘）：**確認 Ollama `/api/tags` → Hermes 新增自訂模型端點 → 以 `qwen3.5:4b` 完成簡單 Coding 與 Browser 任務。

**第二節（約 20 分鐘）：**依設備狀態測試 `qwen3.5:9b`、啟用 Computer Use → 安裝一個簡短的 Skill → 觀看 Remotion／HyperFrames 的本機輸出。**第一次安裝 Node、FFmpeg、Chromium、模型權重通常無法在 20 分鐘內完成，應課前先處理**；有聲影片合成可當延伸練習。

## 前提與限制

- **免註冊是指影片產生與語音合成工具可以選擇不用註冊的本機或免 API 金鑰路線**，不是說 Colab、ngrok、下載模型一定免註冊。你已經有 ngrok URL，這部分視為課前設定。
- Hermes Desktop 可用不需 Nous Portal 訂閱的自訂 OpenAI 相容端點；**瀏覽器雲端供應商、部分媒體模型 API 可能另外要求付費帳號**。
- **Coding、Browser Automation、Computer Use 的實際動作由本機 Hermes 工具執行**；Colab GPU 只用來做模型推論。不要把任務中的瀏覽器誤認為 Colab 遠端桌面。
- **Skills 不是直接生成模型**：它們提供操作步驟、設計規範或使用渲染工具的能力；是否能做出有聲影片，取決於本機依賴、素材與 TTS 是否可用。
- 每個任務都先在測試資料夾執行；不允許 Agent 未經確認就寄信、登入金融服務、刪除正式資料或對外發布。

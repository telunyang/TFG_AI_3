# 04｜免費、免註冊的有聲動畫：從文字到可下載 MP4

## 先釐清可行性

**可以製作有聲動畫，但影片畫面、語音與最後合成通常是三個獨立步驟。** 以下方案以本機開源工具為主，不使用需要另外建立帳號的雲端生成式影片 API；但首次安裝下載套件、語音或模型會使用網路。

1. **畫面：**Remotion 或 HyperFrames 產生動畫 MP4（通常是程式化動態文字／圖形／圖片轉場，不等同 LTX 或 Sora 的寫實生成影片）。
2. **聲音：**使用 `edge-tts` 產生中文 MP3（免 API Key、免安裝 Edge，使用 Microsoft 線上 TTS；服務需連網，非官方穩定性／授權保證）。
3. **合成：**FFmpeg 以 MP4 與 MP3 輸出 `final_with_voice.mp4`；不需要任何 Web API 伺服器。

**如果必須完全離線、完全不使用第三方 TTS 服務**，可以研究 [Piper TTS](https://github.com/rhasspy/piper) 或 [Kokoro](https://github.com/hexgrad/kokoro)，但需額外下載模型、確認繁體中文／臺灣口音效果與系統相容性，故不設為本課預設。

## A. 安裝一次：Node.js、FFmpeg、Python

- Node.js：到 [Node.js 官網](https://nodejs.org/) 下載 LTS。**HyperFrames 官方要求 Node.js 22+**，建議確認你安裝的 LTS 符合。
- FFmpeg：Windows 可從 [FFmpeg 官網](https://ffmpeg.org/download.html) 找 Windows build，macOS `brew install ffmpeg`，Ubuntu `sudo apt install ffmpeg`。
- Python：使用已安裝的 Miniconda／Python 3.10+；Windows 依實際命令可能使用 `py -m pip` 而非 `python -m pip`。

安裝後確認：

```bash
# EN: Show the installed Node.js runtime version.
# 繁中：顯示目前 Node.js 版本。
node --version

# EN: Confirm that FFmpeg is available from the terminal.
# 繁中：確認終端機可以找到 FFmpeg。
ffmpeg -version

# EN: Confirm the Python interpreter version.
# 繁中：確認 Python 解譯器版本。
python --version
```

## B. 建議路線一：Remotion（推薦）

官方提供用 React 產生影格並渲染影片的工具，AI Agent 可以代為建立與編輯專案，**不需要學生先學會 React**；但要讓 Agent 真的執行命令、安裝依賴與輸出成品，而不是只給程式碼。

在本機工作資料夾，使用 Hermes 已安裝的 Remotion Skill 送出 Prompt：

> 在目前工作資料夾中建立最小化 Remotion 專案，製作 10 秒、1280×720、30 FPS 的繁體中文資訊動畫，主題「三個讓工作更有效率的習慣」。每個重點停留至少 2 秒，字體大、背景乾淨、動畫平順。**先生成無聲 MP4** `animation.mp4`，實際執行渲染並檢查檔案存在。不要使用付費圖片／語音／影片 API，也不要要求登入網站。若無法完成，請回報缺少的依賴與實際錯誤。

官方安裝與專案建立方式請看 [Remotion Agent Skills](https://github.com/remotion-dev/skills) 和 [Remotion 文件](https://www.remotion.dev/docs/)。實際的 `npm` 命令可由 Agent 依官方版本與已安裝環境選擇，不必讓學生記 API。

## C. 路線二：HyperFrames（偏好 HTML 時）

HyperFrames 本機命令（官方文件）：

```bash
# EN: Create a new HyperFrames project that contains an HTML animation.
# 繁中：建立可用 HTML 撰寫動畫的 HyperFrames 專案。
npx hyperframes init my-video

# EN: Enter the created project directory.
# 繁中：切換到剛建立的專案目錄。
cd my-video

# EN: Open the local preview to inspect the animation.
# 繁中：在本機預覽動畫效果。
npx hyperframes preview

# EN: Render the local animation to an output video file.
# 繁中：將動畫於本機渲染為影片檔案。
npx hyperframes render
```

可交給 Hermes 的 Prompt：

> 用 HyperFrames 在目前工作目錄製作 8 秒動態短片：米白背景、藍色大標題「今天開始做好時間管理」，依序出現「設定目標、拆解任務、回顧成果」。請使用本機資產和本機渲染，先預覽，再輸出 MP4，不使用 HeyGen Cloud Render 或需要帳號的媒體服務。若 Node 版本不足、缺少 FFmpeg、無法渲染，請顯示錯誤並停止。

**HyperFrames 是 HeyGen 維護的開源製作工具，但使用開源本機渲染不等於可免費使用 HeyGen 全部雲端服務。**

## D. 配音：無需 API Key 的 edge-tts

在本機終端安裝（僅首次）：

```bash
# EN: Install the text-to-speech command-line package.
# 繁中：安裝可以從文字產生語音的命令列套件。
python -m pip install edge-tts

# EN: List voice options and check for Chinese/Taiwanese voices.
# 繁中：列出語音選項，確認可用的中文／臺灣語音。
edge-tts --list-voices
```

**最簡單的臺灣繁體中文配音示例**（若此 voice ID 在清單中可用）：

```bash
# EN: Convert a short Traditional Chinese script into an MP3 voiceover.
# 繁中：將短篇臺灣繁體中文旁白轉成 MP3。
edge-tts --voice zh-TW-HsiaoChenNeural --text "第一步，設定目標。第二步，拆解任務。第三步，回顧成果。" --write-media narration.mp3
```

**重要限制：**`edge-tts` 使用 Microsoft 線上語音服務，不需要另申請 API 金鑰，但它不是完全離線，也不是具備永久 SLA 或商業授權保證的正式雲端 API。要授課前先測試；不同時間可能限速或遭封鎖，對公開發佈與商用應重新確認授權條款。

## E. 合成有聲 MP4，並檢查結果

將 `animation.mp4` 與 `narration.mp3` 放在同一目錄。基本合成方式如下：

```bash
# EN: Add MP3 narration to the silent MP4 without re-encoding its picture track.
# 繁中：保留原影片畫面，加入 MP3 旁白後輸出有聲 MP4。
ffmpeg -y -i animation.mp4 -i narration.mp3 -c:v copy -c:a aac -shortest final_with_voice.mp4

# EN: Inspect the generated file's audio and video streams.
# 繁中：確認完成的檔案真的含有影像與音訊軌。
ffprobe -v error -show_entries stream=codec_type,codec_name -of default=noprint_wrappers=1 final_with_voice.mp4
```

> `-shortest` 表示以最先結束的輸入串流為準。如果旁白比動畫長，聲音會遭裁掉；因此要讓影片長度足夠覆蓋配音，或請 Agent 先估算配音長度並調整影片時間軸。**「檔案存在」不代表影片真的有聲**，要檢查 `ffprobe` 輸出同時有 `video` 和 `audio`。

## F. 把三個步驟一次交給 Hermes 的完整 Prompt

> 請在 `agent-lab/voice-animation` 製作一支 10–15 秒、有繁體中文旁白的 16:9 MP4 影片，主題為「喝水、休息、伸展：三個工作好習慣」。首先檢查 Node.js、FFmpeg、Python、Remotion 是否可用；若缺少依賴，先列出要安裝的內容並等我確認。使用 Remotion 產生動態圖文 `animation.mp4`，不得使用付費或需註冊的外部影像／影片 API。用 `edge-tts` 嘗試產生 `narration.mp3`（優先使用臺灣繁體中文語音）；如果 TTS 網路不可用，不要捏造輸出結果，直接說明。最後使用 FFmpeg 合成 `final_with_voice.mp4`，以 `ffprobe` 檢查同時有 video/audio，列出成品的實際路徑和檔案大小。任何檔案刪除、公開發布或登入操作都須先徵求同意。

## G. 替代途徑：現有三張圖片做手繪影片

[story-to-handdrawn-video](https://github.com/gnipbao/story-to-handdrawn-video) 官方支援**輸入既有、已排好順序的圖片**，輸出**靜音**手繪風格 MP4。使用學生自己提供的素材，可以避免文字生新圖片時可能需要的外部圖片服務。生成靜音 MP4 後再按 D、E 節配音並合成即可。

不要宣稱使用該 Skill 就能自動取得免費、無限制的圖片生成服務；如果 Agent 要呼叫額外圖像 API，應先停下來確認。
